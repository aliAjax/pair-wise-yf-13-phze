# hxyfront-62001 船舶轮机值班记录 · 轮机日志工作台

纯前端轮机日志工作台：值班登记、异常时间线、交接摘要、设备筛选与燃油舱驳运管理。
数据只保存在浏览器（localStorage），刷新保留；不接服务、无第三方运行时依赖。

## 功能

- **班次切换**：六个固定班次（00-04、04-08、08-12、12-16、16-20、20-24），点击开班/切换；已交班班次不可再进。
- **参数登记与看板**：主机转数、滑油回路压力、冷却水温、日用柜耗油量；另可登记舱底水状态与设备异常。
- **异常时间线**：全部异常按时间倒序，可标记已处理。
- **交接班摘要**：末次读数、本班油耗合计、舱底水/异常未闭环项、本班驳运单、交接备注。
- **历史记录**：按主机 / 发电机 / 泵组 / 舱底水 / 燃油系统筛选。
- **燃油舱驳运**：
  - 申报选择起点舱、终点舱、计划时段、申报量；起点存量不足、终点空间不足或时段重叠时**整单不保存**，舱量与日志不动。
  - 驳运单状态：待驳运 → 驳运中 → 已完工 / 待复核 → 已复核。
  - **驳运未结束（待驳运 / 驳运中且时段与本班相交）不能确认交班**。
  - 完工实收偏差 **超过 2%** 即待复核：起点舱先按申报量扣减、终点舱暂不入账；待复核单**复核前不得修正/撤销**，复核通过后终点舱按实收补入账。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/state.ts` | 状态、类型、localStorage 持久化、种子数据、全部变更动作 |
| `src/rules.ts` | 纯业务规则：申报校验、时段重叠、2% 偏差、过账计算、交班阻断、班次摘要 |
| `src/pages.tsx` | 页面与交互（调用 rules 校验，再提交 state 动作） |
