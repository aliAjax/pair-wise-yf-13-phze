# 船舶轮机值班记录 · 轮机日志工作台

面向轮机员当班记录的纯前端工作台：切换班次、登记机舱四项指标、记录舱底水与设备异常、
办理燃油舱驳运、交接摘要与设备筛选。数据只保存在浏览器 `localStorage`，不接服务、不加运行时依赖。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `src/state.ts` | 数据类型、初始数据、`localStorage` 持久化（`marine-engine-log:v1`）、`useStore` 与全部动作入口 |
| `src/rules.ts` | 纯函数业务规则：范围校验、驳运三关、2% 偏差复核、交班拦截、时间格式化 |
| `src/pages.tsx` | 页面与交互：班次栏、指标看板、登记表单、驳运单卡片、时间线、交接摘要、设备筛选、历史流水 |

## 业务规则

- 班次：6 个四小时班次（00-04 … 20-24），可切换/补开；确认交班后本班记录全部锁定只读。
- 四项指标：主机转速、滑油回路压力、冷却水温、日用柜耗油量；耗油同步扣减日用柜存量，
  存量不足则整笔不保存、舱量与日志不动。
- 驳运单三关（任一不过整单不保存，舱量与日志不动）：
  1. 起点存量 ≥ 申报量；
  2. 终点空位 ≥ 申报量；
  3. 计划时段与任何已存驳运单不重叠（首尾相接允许）。
- 驳运流程：待开工 → 进行中 → 完工。待开工/进行中/待复核均属于“未结束”，未结束不能确认交班。
- 完工偏差 `|实收 − 申报| / 申报 > 2%`：起点舱先按实收扣减、终点舱暂不入账、单据转待复核；
  复核前不得重新完工/开工/删除。复核通过则终点补入账并完成；复核退回则回进行中可重新登记完工。
- 设备筛选（全部/主机/发电机/泵组/舱底水/燃油驳运泵）同时作用于异常时间线与历史流水。
